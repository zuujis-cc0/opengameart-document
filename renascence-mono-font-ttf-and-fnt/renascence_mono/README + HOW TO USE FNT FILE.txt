.FNT file instructions:

For Godot, put the .fnt file into the same folder as the .png, and also be sure to import both at the same time. In the Inspector tab with your RichTextLabel selected (or whatever you're using), set its theme to a new or custom theme, and then set the font to Renascence Mono. Set the character size to 8, and then find 'Texture' in the inspector and set 'Filter' to 'Nearest.'


.TTF file instructions:
For Godot, import the .ttf. In the Inspector tab with your RichTextLabel selected (or whatever you're using), set its theme to a new or custom theme, and then set the font to Renascence Mono.

For Unity, import the .ttf, right click it, and then select Create > TextMeshPro > Font Asset.
